# STAMPED

The Adelaide Manhole Project

Reimagining the city beneath our feet.

## About

STAMPED is a public art and civic storytelling initiative exploring how Adelaide's manhole covers can become permanent public artworks inspired by Japan's artistic manhole cover program.
